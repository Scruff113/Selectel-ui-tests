# Автотесты Selectel

## Реализованные проверки

### 1) Главная страница
- Страница открывается
- В заголовке страницы есть слово **Selectel**

### 2) Страница «Цены»
- Страница открывается по адресу https://selectel.ru/prices/
- В URL присутствует `/prices`
- На странице присутствует слово **«Цены»**

### 3) Страница авторизации
- Открывается страница логина https://my.selectel.ru/login
- URL содержит `login`
- Сервер отвечает со статусом **200** (успешный ответ сервера)

## Используемые инструменты
- Python 3.11
- Pytest
- Playwright
- pytest-playwright

## Как запустить проект локально

1) Установить Python 3.10+

2) Установить зависимости:
pip install -r requirements.txt

3) Установить браузеры Playwright:
python -m playwright install

4) Запустить тесты:
pytest
